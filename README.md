# useNaviDate( )

**useNaviDate( ) 는 사용자를 위한 데이트 코스 추천 사이트입니다.**</br>연인 뿐 아니라 친구, 가족 등 가까운, 혹은 가까워질 사람들과 기분 좋은 하루를 보낼 수 있는 최적의 루트를 추천해드려요! 물론 직접 추천하는 것도 가능합니다 😊

✅ 홈화면(useNaviDate()) – 사용자가 직접 등록할 수 있는 데이트 루트 추천 페이지예요.<br>
✅ 커뮤니티(NaviTalk) – 추천 루트를 사용해본 사용자들의 후기를 한곳에서!<br>
✅ 지역을 기반으로 데이트 코스를 추천받을 수 있고, 예산에 맞춰 PICK 할 수 있어요.</br>
✅ MyPage – 사용자가 작성한 게시글을 MyPage 에서 모아볼 수 있어요!<br>

<br>

## 프로젝트 소개📄

**📆 프로젝트 기간 : 2025.02.26 ~ 2025.03.05**

### 🗺️ useNaviDate() - 당신만의 데이트 코스를 추천하고 공유하세요!

데이트를 계획할 때 어디로 갈지 고민된다면?</br>
가족과의 여행, 친구와의 나들이 장소를 정하기 힘들다면?</br>
**useNaviDate** 는 여러분이 직접 경험한 최고의 데이트 코스를 추천하고 공유할 수 있는 플랫폼입니다.

🎨 전시회, 🍿 영화관, 🍽️ 맛집, ☕ 카페 등 다양한 장소를 조합하여 **나만의 데이트 코스**를 등록하고, 다른 사용자가 공유한 데이트 코스를 확인하고, **직접 다녀온 후기를 남길 수 있는 커뮤니티 기능**까지 제공합니다.

이제 데이트 코스를 고민하지 말고, **useNaviDate()** 에서 가장 로맨틱한 순간을 계획해보세요!

---

### 🚀 useNaviDate가 제공하는 주요 기능</br>

**지도 기반 데이트 코스 추천** </br>
✅ 사용자는 특정 지역을 선택하고, 직접 코스를 등록할 수 있음</br>
✅ 여러 장소(전시회, 영화관, 맛집, 카페 등)를 순서대로 등록하여 동선까지 고려한 추천 코스 작성 가능</br>

**사용자 경험 기반 커뮤니티 게시판** </br>
✅ 다른 사용자가 등록한 데이트 코스를 보고, 직접 다녀온 후기를 댓글로 공유</br>
✅ 각 코스나 특정 스팟에 대한 평점 및 리뷰 기능 제공</br>

\***\*회원가입 및 개인화 기능** </br>
✅ 회원가입 후 자신만의 추천 코스 작성 가능</br>
✅ 내가 작성한 코스 및 후기를 관리할 수 있는 마이페이지 제공</br>
